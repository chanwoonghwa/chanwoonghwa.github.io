실시간 연결 설정

Firebase Realtime Database와 Email/Password 인증을 사용합니다. Firebase에서 관리자 계정과 데이터베이스 보안 규칙을 먼저 구성해야 합니다.

프로젝트 scoreboard-c4572의 웹 앱 설정과 데이터베이스 주소를 적용했어요. 페이지가 자동으로 Firebase에 연결됩니다. 관리자 로그인과 데이터베이스 보안 규칙이 설정되어 있어야 실제로 점수 수정이 가능합니다. Firebase 프로젝트 설정 열기 ↗ → 내 앱에서 웹 앱을 등록하고 Config 전체를 복사해 아래에 붙여넣으세요. const firebaseConfig = {...} 형태도 지원합니다.

공유 링크는 Firebase의 공개용 웹 앱 설정을 포함합니다. 서비스 계정 키나 관리자 비밀번호를 입력하지 마세요.

운영자 로그인

실시간 연결 후 관리자 로그인이 가능합니다.

운영자 계정 생성: Firebase Console → Authentication → Sign-in method → Email/Password 활성화 → Users에서 관리자 등록. Database Rules에서 승인된 관리자 UID만 쓰기 허용하세요.

Firebase Realtime Database 권장 보안 규칙
ADMIN_UID를 Firebase Authentication 사용자 UID로 치환하세요. 공개 읽기이므로 점수와 이름은 누구나 볼 수 있습니다.
