## 거리 데이터

거리 API는 사이트 실행 시 호출하지 않습니다. **초기 61개 식당의 자동차 주행거리 데이터는 미측정**입니다. 주행거리(km)는 네이버지도 자동차 길찾기에서 수도전기공업고등학교(서울 강남구 개포로 410) → 각 식당으로 한 번 조회해 입력할 수 있습니다. 값을 임의로 계산하지 않았습니다.

웹의 `거리 입력` 값은 현재 브라우저 localStorage에만 저장됩니다. `필터 결과 CSV`로 내려받을 수 있지만 다른 사용자에게 자동 공유되지는 않습니다.

전체 사용자에게 거리값을 배포하려면 이 폴더의 `restaurants.json`의 `route_distance_km` 및 `route_duration_min`을 채우고, HTML 내부 `id="restaurant-data"` JSON을 같은 내용으로 갱신해야 합니다. 지금의 `index.html`은 단독 실행을 위해 정적 JSON을 내장하며, 이 JSON 파일을 실행 시 직접 읽지는 않습니다.

## 데이터 검증 유의사항

- 일부 식당은 일요일 22시 정각 마감 및 라스트오더 선확인 필요
- 10명 단체석, 매장 주차 가능 대수, 대체 주차장 빈자리는 예약 전에 전화 확인
- 이 목록은 일요일 저녁 식당 **후보**이며, 61곳 모두가 검증 완료된 것은 아닙니다
- 소주·맥주 위주 펍은 제외하고 치킨집은 허용합니다

데이터 수정 후 GitHub Pages가 게시 브랜치의 `docs/`를 자동 배포합니다.
